## Como trabalhamos

<p align="center">
  <img src="assets/fluxo.svg" alt="Do dado à decisão: dados, análise e decisão" width="100%">
</p>

- **Uma fonte de verdade.** Cada número tem origem conhecida e regra documentada.
- **Clareza antes de enfeite.** Painéis simples, cores com significado e pouco texto.
- **Automação com segurança.** Os sistemas de origem só são lidos, nunca alterados.
- **Método antes de opinião.** Previsões e metas são testadas contra o que realmente aconteceu.
